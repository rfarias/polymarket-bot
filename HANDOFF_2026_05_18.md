### 3. Chart Context BTC — Fase 1: Logging (commit `d142417`)

Esta é a parte principal do trabalho da manhã. Adicionamos análise gráfica de BTC ao guardian e ao runner, **apenas para logging** — sem bloquear ordens ainda.

#### Módulos novos

**`market/btc_chart_context_v1.py`** — engine de contexto gráfico:

```text
Fonte: Binance API (klines BTC/USDT, 5min e 15min)
Cache: 1 resultado por bucket de 5min, TTL 60s (não bate a API a cada poll)

Calcula:
  EMA9 / EMA21 → trend_5m: "UP" | "DOWN" | "NEUTRAL"
  Pivôs → at_resistance, at_support, resistance_level, support_level
  Padrão do último candle → last_candle_pattern, last_candle_bias
    exemplos: hammer, shooting_star, bearish_engulfing, bullish_engulfing, doji, marubozu, ...
  Alinhamento 15min → is_15m_aligned, trend_15m (só quando no boundary)

Saída: BtcChartContext.get_penalty_for_side(side) → float [0.0, 1.0]
  0.0 = com a tendência ou neutro
  1.0 = contra a tendência (máximo de penalidade)
```

**`analyze_chart_context_on_logs.py`** — replay offline em logs:

```text
Lê logs JSONL paper/real (eventos enter+exit) e busca o contexto histórico da Binance
para cada entrada. Compara outcome com e sem filtro.

Uso:
  python analyze_chart_context_on_logs.py --dir logs
  python analyze_chart_context_on_logs.py --logs logs/my_paper.jsonl --threshold 0.4
  python analyze_chart_context_on_logs.py --threshold 0.80  # só candle conflitante
```

#### Integração no guardian
